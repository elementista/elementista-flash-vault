Manual de Operação e Configuração
Elementista Vault

Este guia reúne de forma simples e direta os comandos essenciais que você realmente precisa usar enquanto executa jogos no emulador.

Para jogar mega drive ou o super nintendo - deixei as teclas A S D, Z X C = botões de ação, ENTER = start, BARRA DE ESPAÇO = select

Para jogar atari 2600 as teclas padrão é F1 = para dois players, F2 = start, BARRA DE ESPAÇO = botão de ação

As setas direcionais do teclado serve para movimentos, para cima, para baixo, para a esquerda, para a direita.

Abaixo deixo um mini manual para configurar de acordo com o que você queira.

1. Comandos Vitais de Tela e Ajuda

Alt + Enter

Alterna instantaneamente entre o modo Tela Cheia (Fullscreen) e o modo Janela.

Alt + F4

Fecha instantaneamente o modo Tela Cheia (Fullscreen) ou modo Janela. (resumindo fecha o game)

F1

Abre a Documentação de Ajuda Integrada direto na tela do emulador. Mostra a lista completa de atalhos e funções em tempo real.

Esc

Fecha e sai imediatamente do emulador de forma segura.

2. Como Configurar e Mapear os Controles

O emulador salva os controles de forma individual para cada videogame simulado. Siga estes passos simples com o jogo já aberto:

  1. Pressione Alt + Shift + 1 para iniciar a configuração do Player 1 (use 2, 3, etc., para outros jogadores).
  2. Olhe na parte inferior da tela: o emulador mostrará o nome do botão original do console (ex: UP, DOWN, BUTTON A).
  3. Aperte o botão correspondente no seu teclado ou controle físico duas vezes seguidas para confirmar.
  4. Se quiser deixar um botão sem função (pular), aperte a tecla F5.
Importante: Se errar ou o controle bugar, pressione Alt + Shift + C para limpar (limpar) todas as configurações e começar o mapeamento do zero.

3. Alternando Tipos de Controle (Analógico / 6 Botões)

Alguns sistemas exigem a troca do tipo de dispositivo conectado (ex: ativar o analógico do PS1 ou mudar o controle do Mega Drive de 3 para 6 botões):

  • Pressione Ctrl + Shift + 1 para rodar entre os tipos de periféricos disponíveis na porta do Player 1.
  • Continue apertando até que apareça a opção desejada na tela (ex: dualshock, gamepad (6-button)).

4. Outros Atalhos Essenciais para Jogadores

  • Salvar Jogo Rápido (Save State): Pressione F5 (salva no slot selecionado).
  • Carregar Jogo Rápido (Load State): Pressione F7 (recarrega do slot selecionado).
  • Mudar Slot de Salvamento: Pressione as teclas numéricas de 0 a 9 para escolher slots diferentes.
  • Reiniciar o Jogo (Reset): Pressione F11.
  • Avanço Rápido (Fast Forward): Mantenha pressionada a tecla ` (Crase/Til abaixo do Esc) para acelerar o jogo.
  • Captura de Tela (Screenshot): Pressione F12.
